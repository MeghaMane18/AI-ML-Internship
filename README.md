Student Performance Data Explorer

1. Project Overview
The Student Performance Data Explorer is a beginner-level data analysis project developed using Python. It explores student marks and identifies patterns through statistical analysis and visualizations.

2. Objectives
- Load student data using Pandas.
- Explore dataset columns and data types.
- Check missing values and duplicate records.
- Calculate mean, median, and mode.
- Visualize student scores using different charts.
- Export a cleaned dataset.

3. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

4. Project Structure
- data/ — Input and cleaned CSV datasets
- notebooks/ — Jupyter Notebook analysis
- src/ — Python source code
- reports/ — Final analysis report
- images/ — Screenshots of graphs

5. Analysis Performed
- Dataset exploration and descriptive statistics
- Missing-value analysis
- Duplicate detection and removal
- Mean, median, and mode calculations
- Histogram, scatter plot, box plot, and correlation heatmap

6. How to Run
1. Install the required Python libraries.
2. Open "notebooks/student_performance_eda.ipynb" in VS Code.
3. Select the correct Python kernel.
4. Run the notebook cells in order.

7. Dataset
The project uses sample student score data for practice.

8. Conclusion
This project demonstrates basic data cleaning, statistical analysis, and data visualization using Python libraries.
